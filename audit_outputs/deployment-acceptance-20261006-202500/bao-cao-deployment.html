Kế Hoạch Rollback

  • Tắt Nóng Jev (Zero Downtime):
    - Đặt JEV_MODE=shadow trên Railway: Luồng chat dùng 100% baseline, Jev chỉ log giám sát.
    - Đặt JEV_MODE=off trên Railway: Bỏ qua hoàn toàn Jev Engine (0 API call, 0 latency).
  • Rollback trên Railway:
    Truy cập Dashboard Railway → Chọn Service → Deployments → Bấm Rollback về phiên bản trước.
  • Rollback trên Vercel:
    Truy cập Dashboard Vercel → Deployments → Bấm Instant Rollback về bản deploy trước.
